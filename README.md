# Groenhouten Dairy Farm

Rebuilt from the Otis Farm Ventures template for Groenhouten Dairy Farm
(Leuth, Netherlands) — raw milk, raw-milk cheese and dairy cattle.

## Notes for handoff

- **Images**: since no farm photos were supplied, all product/hero images
  are hotlinked from free-to-use stock libraries (Unsplash + Pexels,
  standard licenses — free for commercial use, no attribution required).
  They are linked directly by URL, not stored in `/images`. Swap in real
  farm photography whenever it's available — replace the `src` values in
  the HTML with local files in `/images` for full control and faster
  loading.
- **Logo**: `images/logo.svg` is a custom circular wordmark built for this
  project (ring text + serif "G" monogram). Vector, so it scales cleanly
  at any size — no separate favicon needed.
- **Language**: a Google Translate widget (EN default, NL selectable) sits
  in the nav on every page.
- **WhatsApp**: all "Order Now" actions and the contact form open WhatsApp
  pre-filled, using +31 6 13755767.
- **Domain**: no `CNAME` file included — add one once a domain is chosen.
